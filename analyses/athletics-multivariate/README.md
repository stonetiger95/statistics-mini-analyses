# 여러 육상 기록에 공통된 구조는 무엇인가

## 1. 분석 질문

54개 국가의 여자 육상 7종목 기록에서 공통된 변동 축을 찾고, PCA와 요인분석이 보여주는 구조를 비교합니다.

## 2. 데이터

100m, 200m, 400m, 800m, 1500m, 3000m, 마라톤 국가기록입니다. 원 출처는 *IAAF/ATFS Track and Field Handbook for Helsinki 2005*로 확인했으나 재배포 허가가 명확하지 않아 원자료는 포함하지 않습니다.

## 3. 사용 방법

단거리(초)와 중·장거리(분)의 척도가 달라 상관행렬 기반 PCA를 사용했습니다. 같은 표준화 자료에 2요인 principal-component factor analysis(PCFA)와 maximum-likelihood factor analysis(MLFA)를 적용했습니다.

## 4. 주요 결과

- PCA의 PC1은 82.97%, PC2까지는 91.95%의 분산을 설명했습니다.
- PC1은 모든 종목과 같은 방향의 큰 적재를 보여 기록 전반의 공통 변동을 요약했습니다.
- PC2는 100~400m와 800m 이상 종목의 상대적 대비를 나타냈습니다.
- PCFA 2요인은 91.95%, MLFA 2요인은 88.62%의 공통 변동을 요약했습니다. MLFA의 두 번째 요인은 PCFA보다 약했고 800m·마라톤 적재가 0에 가까웠습니다.

## 5. 해석

PCA와 FA 모두 강한 첫 공통 축과 단거리–중장거리 대비라는 보조 축을 보였습니다. PCA는 총분산 요약, FA는 공통분산 모형이라는 목적 차이가 있으므로 수치와 의미를 동일시하지 않습니다. 적재 부호는 임의적입니다.

## 6. 한계

2개 차원 선택은 scree plot과 누적 설명력에 주로 의존하고 별도 표본 검증이 없습니다. 국가기록은 국가의 선수층·측정 시점·제도적 차이를 함께 반영하므로 선수 개인의 능력이나 원인으로 해석할 수 없습니다.
