# AZT 처치 시점과 AIDS 증상 범주의 상대적 구조

## 1. 분석 질문

AZT 즉시·지연 처치와 3년 내 AIDS 증상 발생 여부가 만든 2×2 분할표의 상대적 연관 구조를 대응분석으로 어떻게 표현할 수 있는지 살펴봅니다.

## 2. 데이터

338명의 집계표입니다. 즉시 처치군은 증상 있음 25명·없음 145명, 지연 처치군은 각각 44명·124명입니다. 공개 문헌의 집계값만 사용하며 개인 수준 자료는 없습니다.

## 3. 사용 방법

행 조건부 비율과 Pearson 카이제곱 검정을 확인한 뒤, 표준화 잔차 행렬의 SVD로 단순 대응분석을 직접 계산했습니다.

## 4. 주요 결과

- 증상 발생 비율은 즉시 처치군 14.7%, 지연 처치군 26.2%였습니다.
- Pearson 카이제곱 검정은 χ²=6.860, df=1, p=0.0088이었습니다.
- 2×2 분할표이므로 두 범주의 연관 구조는 하나의 축으로 요약됩니다. 효과크기 Cramér's V는 0.142로, 통계적으로 유의한 차이가 강한 연관성을 의미하지는 않았습니다.

## 5. 해석

1차원에서 즉시 처치와 무증상, 지연 처치와 증상 있음이 각각 같은 상대적 방향에 놓입니다. 즉시 처치군에서 증상 발생 비율이 더 낮게 관찰됐지만, 공개된 집계표만으로 임상적 인과효과를 확정할 수는 없습니다.

## 6. 한계

공개 집계표만으로 무작위화 절차, 추적 손실, 기저 위험과 표본 선정의 세부를 재검증할 수 없습니다. race를 포함한 원본 3원 구조를 공개본의 주 분석에서 제외했으며, 2×2 CA는 시각적 차원 축소의 이점이 제한적입니다.
