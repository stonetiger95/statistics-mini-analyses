# 주가 수준에서 확인한 시계열 구조와 단기 기준선

## 1. 분석 질문

2024년 고려아연 종가의 비정상성과 자기상관 구조를 확인하고, ARIMA(0,1,0)이 어느 정도의 단기 기준선을 제공하는지 살펴봅니다.

## 2. 데이터

KRX에서 받은 2024년 244거래일 종가와 2025년 첫 5거래일 종가를 사용했습니다. KRX 이용약관을 고려해 원자료는 재배포하지 않으며 [획득 방법](../../data/README.md)만 제공합니다.

## 3. 사용 방법

거래일 인덱스의 가격 수준과 1차 차분을 확인하고, 교육 목적의 ARIMA(0,1,0)을 적합했습니다. Ljung–Box 검정으로 잔차를 진단하고 5거래일 기준선 예측을 실제 관측값과 제한적으로 비교했습니다.

## 4. 주요 결과

- 가격 수준은 강한 추세와 변동성 변화를 보였고, 1차 차분 후에도 일부 시차 의존성이 남았습니다.
- ARIMA(0,1,0)의 다음 5개 점예측은 마지막 관측값인 1,006,000원으로 일정했습니다.
- 잔차 Ljung–Box 검정은 lag 6, 12, 18에서 각각 p=0.0055, 0.0026, 0.0284로 자기상관 잔존을 보였습니다.

## 5. 해석

이 모형은 유효성이 충분히 확인된 예측모형이 아니라 **baseline forecast**입니다. 실제 5개 값이 95% 예측구간 안에 있었던 사실만으로 predictive validity가 입증되지는 않습니다.

## 6. 한계

가격 수준 ARIMA는 교육 목적입니다. 원본의 달력일 확장(`frequency=365`)과 휴일 전일값 대체는 인위적 자기상관을 만들 수 있어 공개본에서는 제외했습니다. 금융 시계열에는 거래일 인덱스나 수익률 기반 접근이 더 자연스럽고, 변동성 모형·더 긴 외부 검증도 필요합니다.
