# 반복 검정에서 거짓 양성은 어떻게 누적되는가

## 1. 분석 질문

10,000개 가설을 동시에 검정하면 보정하지 않은 p-value의 거짓 양성이 얼마나 누적되며, Bonferroni와 BH-FDR은 오류와 검정력의 균형을 어떻게 바꾸는지 확인합니다.

## 2. 데이터

외부 데이터 없이 1,000회 합성 실험을 수행합니다. 각 반복에서 가설별로 10% 확률로 대립가설을 지정하고, 검정통계량은 대립가설에서 N(2, 1), 귀무가설에서 N(0, 1)로 생성합니다. Seed는 12345로 고정했습니다.

## 3. 사용 방법

양측 z-test p-value에 대해 unadjusted, Bonferroni, BH 보정을 비교합니다. 평균 기각 수·거짓 양성 수, 하나 이상의 거짓 양성이 생긴 반복 비율(FWER), 평균 FDP, power를 기록합니다.

## 4. 주요 결과

보정하지 않은 검정은 반복당 평균 451.0개의 거짓 양성을 만들었고 FWER은 1.000, 평균 FDP는 0.466이었습니다. Bonferroni는 FWER을 0.039로 낮추는 대신 power가 0.005로 감소했습니다. BH는 평균 FDP를 0.046으로 유지하면서 power 0.050, 평균 기각 52.3개로 Bonferroni보다 더 많은 신호를 남겼습니다. BH의 FWER은 0.860으로 높았는데, 이는 BH가 FWER이 아니라 FDR을 제어한다는 점과 일치합니다.

## 5. 해석

어떤 보정이 “최선”인지는 목표에 달려 있습니다. 단 하나의 거짓 양성도 중요한 경우 FWER 제어가, 발견 목록에서 거짓 발견의 평균 비율을 관리하려는 경우 FDR 제어가 더 자연스럽습니다.

## 6. 한계

검정통계량은 서로 독립이고 효과크기는 하나의 값으로 고정되어 있습니다. 실제 연구의 상관 구조, 효과크기 이질성, p-value 모형 오지정에서는 결과가 달라질 수 있습니다.
